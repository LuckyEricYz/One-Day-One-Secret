## 一、 核心逻辑：天地人·三位一体

我们将「天、地、人」作为「一日天机」生成算法的三个加权维度：

### 1. 天（时空坐标 / 随机动力学）

- **逻辑：** 利用当前时间（天干地支/节气）作为算法种子。
- **天机点：** 比如今日是“惊蛰”，天地间“木气”升发。算法会自动调高“疏肝”、“动能”相关的权重。
- **起卦：** 用户在屏幕上长按或随机输入的数字，映射为六十四卦之一（如：_雷天大壮_），作为今日的“势”。

### 2. 地（知识库 / RAG 检索增强）

- **逻辑：** 这是一个**专业的养生语义库**。
- **内容：** 包含《黄帝内经》等古籍，以及现代营养学、运动生理学。
- **调教：** AI 不再是瞎编，而是从库中检索出与“木气升发”和“大壮卦”最匹配的健康条目（如：多食青色食物、避免剧烈运动）。

### 3. 人（个性化画像 / 实时体征）

- **逻辑：** 这是工具最“准”的地方。
- **输入：** \* **静态：** 用户预设的体质信息（如：长期熬夜、血压波动、代谢压力）。
  - **动态：** 今日心情评分或简单的“舌诊”上传。
- **作用：** AI 会根据这些“人”的变量，对“天”和“地”的结果进行**去偏与矫正**。

## 二、 极简版思路实现（H5 快速落地）

为了实现“快速开发”，我们采用 **“数据预处理 + AI 实时翻译”** 的轻量方案。

### 1. 交互流：从“缘起”到“领悟”

1.  **缘起（Input）：**
    - 用户打开 H5，屏幕显示：“请平复呼吸，长按屏幕感应今日天机。”
    - 后台自动获取：**地理位置（天气/湿度） + 实时时间（干支/节气）**。
2.  **推演（Compute）：**
    - 系统快速运算：`卦象(随机种子) + 节气(环境常数) + 用户健康标签(变量)`。
    - **AI 生成：** 调用 LLM，将以上三个维度的信息聚合成一段文字。
3.  **显像（Output）：**
    - 视觉呈现一张“天机卡”。
    - **卡片构成：**
      - **天机语：** 一句极具玄学韵味的判词（如：_“震雷当头，宜敛不宜散”_）。
      - **身密码：** 结合科学的养生建议（如：_“今日心率变异度可能降低，宜早睡，忌生冷，宜按揉内关穴”_）。

### 2. 多模态的“低成本”替代方案

在 MVP 阶段，不需要复杂的图像识别：

- **舌诊替代：** 给用户 3 个典型的舌头示意图，让其选一个最接近自己的。
- **表情替代：** 用 Emoji 选择器，让用户选出现在的状态。

## 三、 技术路线：Web + H5 快速栈

既然要快，我们用 **Serverless + AI API** 的“拼积木”方式：

| 模块        | 推荐技术                                   | 理由                                                           |
| :---------- | :----------------------------------------- | :------------------------------------------------------------- |
| **前端**    | **React + Tailwind CSS**                   | 响应式极佳，Tailwind 能快速做出“新中式”的高级感。              |
| **动画**    | **Lottie 或 Framer Motion**                | 实现那个“粒子聚散成卦”的神秘动效，不吃性能。                   |
| **后端**    | **Vercel / Cloudflare Workers**            | 免费额度大，无需配置服务器，部署一行代码搞定。                 |
| **AI 引擎** | **Gemini 3 Flash**                         | **首选**。响应极其迅速（适合 H5 实时交互），且理解逻辑能力强。 |
| **知识库**  | **Vector Database (如 Pinecone/Supabase)** | 存储你整理好的《养生数据库》，通过 RAG 给 AI 加装“大脑”。      |

## 五、 给你的“调教”小锦囊

在训练 AI 做“解卦人”时，记得给它立一个 **“温柔的观察者”** 的人设：

- **不要说：** “你应该去跑步。”（这太像说教）
- **要说：** “今日风动雷起，你的身体能量偏向发散，尝试在黄昏时慢走 20 分钟，会有意想不到的平静。”

你打算让用户在进入工具时，先录入一些基础的健康指标（比如你之前关心的那些血压或代谢因子），还是让他们通过“抽签”后再补录信息？
