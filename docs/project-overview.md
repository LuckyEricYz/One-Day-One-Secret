# 一日天机项目总览

> 一款以“固定双角色 + 每日一卦 + 一站式养生面板”为核心体验的 Web/H5 应用。

## 1. 产品定位

当前版本把每日内容收敛成一张轻量日历面板：

- 天：上海日期、节气、干支
- 人：固定男 / 女角色预设
- 用：卦象提示、轻动作、穴位、家常食谱

目标不是算命，也不是健康诊断，而是提供一套简单、可重复、零学习成本的每日调理建议。

## 2. 当前版本范围

当前主链路固定为：

1. 首次选择固定角色
2. 自动弹出今日卦象
3. 首页查看 4 个模块
4. 按 `Asia/Shanghai` 自然日自动更新
5. 本地查看历史快照

当前明确不做：

- 问卷画像
- 粒子成卦与长按仪式
- 当日补录
- AI 生成结果卡
- 长图保存
- 每日额度
- 账号与跨设备同步

## 3. 技术口径

| 模块 | 当前决策 | 说明 |
|:-----|:---------|:-----|
| 前端 | Vite + React | 单仓 Web/H5 共用 |
| 样式 | Tailwind CSS + CSS 变量 | 纸本留白主题 |
| 内容生成 | 纯本地规则 | 角色预设 + 日期 + 节气 + 内容池 |
| 存储 | LocalStorage | 当前角色、弹窗已读、历史快照 |
| 对外接口 | 无必需运行时接口 | `/api/generate` 不再是当前主链路 |

## 5. 统一决策

- 同一角色在同一上海日期下，多次打开必须得到相同快照
- 每个角色每天只保留 1 条历史记录
- 角色切换后立即重算当天内容，并重新弹出今日卦象
- 所有输出都保持“生活方式建议”口径，不作医学结论
- 旧的服务端 AI 生成链路不再参与当前版本运行时主流程
