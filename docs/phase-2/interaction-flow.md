# 用户交互流程

> 当前版本采用“角色先行、首页直达”的极简链路。

## 1. 总体链路

```text
首次使用：
打开应用
  -> 首次角色 schema 校验，必要时清空旧角色历史
  -> / 自动跳转 /role
  -> 选择固定角色
  -> 自动弹出今日卦象
  -> 进入首页四模块
  -> 可打开历史快照

非首次使用：
打开应用
  -> 读取上次角色
  -> 生成今日快照
  -> 自动弹出今日卦象
  -> 进入首页四模块
  -> 可跳转 /role 切换角色 / 打开历史快照
```

## 2. 启动逻辑

1. 若不存在 `tianji_v2_role_id`，访问 `/` 时自动进入 `/role`
2. 若已存在角色，直接生成当天快照
3. 若当天角色弹窗未读，默认弹出今日卦象
4. 历史快照始终可从头部入口查看
5. 已选角色访问 `/role` 时仍显示角色选择页，用于重新选择或进入首页

## 3. 角色选择

固定两个角色：

- `role_a`：`职场男生`
- `role_b`：`职场女生`

角色卡必须展示：

- 基础状态
- 流年 / 八字摘要
- 年度宜忌
- 情绪特质
- 视频头像和静态 poster 兜底

要求：

- 不再要求用户手动输入任何信息
- 点击角色后立即进入当天内容
- 切换角色时重新计算当天快照

## 4. 今日卦象弹窗

### 4.1 触发规则

- 首次选择角色后立即弹出
- 已有角色时冷启动默认弹出
- 同一角色同一天关闭后，本会话和刷新后都不重复打断
- 跨日或切换角色后再次弹出

### 4.2 展示内容

必含：

- 卦名
- 六爻图
- 一句今日主轴
- 一段通俗养生解释
- 2-3 个焦点标签

## 5. 首页四模块

首页固定展示以下 4 块：

1. `当日一卦`
2. `带薪健身`
3. `每日穴位`
4. `节气食谱`

布局要求：

- 手机端单列
- 桌面端 2x2 卡片
- `带薪健身` 顶部展示 3 个预制静音循环动作视频，文字规则推荐仍保留
- 不再有问卷、成卦、补录、结果卡的分步骤切屏

## 6. 每日自动更新

- 以 `Asia/Shanghai` 自然日 `00:00` 为准
- 跨日后重新生成 `DailySnapshot`
- 重新触发当天角色的卦象弹窗
- 同一天重复打开只复用同一份快照

## 7. 历史快照

### 7.1 规则

- 以 `roleId + dateKey` 作为唯一键
- 每个角色每天只保留一条记录
- 列表按日期倒序显示

### 7.2 展示

- 日期
- 角色标签
- 卦名
- 当天动作、穴位、食谱摘要

## 8. 本地存储

```text
tianji_v2_role_id
tianji_v2_history
tianji_v2_modal_seen
tianji_v2_role_schema
```

`tianji_v2_role_schema` 用于角色改版清理。版本变化时会清除旧角色、旧历史和旧弹窗已读记录。
