# 用户交互流程

> 当前版本采用“两段式天机流”：先显卦与天机语，再补录，最后生成终极卡。

## 1. 总体链路

```text
首次使用：
打开应用
  -> 生成 tianji_client_id
  -> 5 题问卷
  -> 今日状态选择
  -> 粒子成卦
  -> 即时天机语
  -> 3 题补录
  -> 结果卡
  -> 保存长图 / 查看历史

非首次使用：
打开应用
  -> 今日状态选择
  -> 粒子成卦
  -> 即时天机语
  -> 3 题补录
  -> 结果卡
  -> 保存长图 / 查看历史
```

## 2. 启动逻辑

1. 若不存在 `tianji_client_id`，生成随机 UUID 并写入本地
2. 若不存在 `tianji_profile`，进入首次问卷
3. 若已存在画像，直接进入今日状态选择
4. 历史记录始终可从头部入口查看，不额外计数

## 3. 首次问卷

前 4 题单选，第 5 题多选：

| 题号 | 问题 | 选项 |
|:-----|:-----|:-----|
| 1 | 你的睡眠质量如何？ | 经常失眠浅眠 / 偶尔不好 / 一般都很好 |
| 2 | 你的手脚温度？ | 经常冰凉 / 有时偏凉 / 一般温暖 |
| 3 | 你的消化状况？ | 容易胀气不适 / 容易腹泻 / 很少有问题 |
| 4 | 你的情绪状态？ | 容易焦虑紧张 / 容易压抑低落 / 基本平稳 |
| 5 | 你最近更接近哪些习惯？ | 长期久坐 / 经常熬夜 / 饮食不规律 / 规律运动 |

写入本地结构：

```json
{
  "constitution": "qi_deficiency",
  "healthTags": ["late_sleep", "sedentary"],
  "createdAt": "2026-04-11T13:30:00.000Z",
  "updatedAt": "2026-04-11T13:30:00.000Z",
  "version": 1
}
```

## 4. 今日状态选择

状态枚举固定为：

- `happy`
- `calm`
- `tired`
- `anxious`
- `sad`
- `angry`

交互要求：

- 页面首次可见后 300ms 内完成可交互
- 点击状态后立即进入粒子成卦页
- 不增加确认弹窗

## 5. 粒子成卦

### 5.1 终端差异

- Web：点击粒子球，立即成卦
- H5：长按粒子球至少 `2000ms`，达到阈值后自动成卦

### 5.2 行为规则

- 成卦瞬间前端本地计算卦象，不等待接口
- 即时显示：卦名、六爻形态、一句“天机语”
- 若 H5 长按未满 2 秒松开：提示“再静心一会儿”
- 在成卦阶段并行准备 `timestamp`、`timezone`、授权后的 `location`

## 6. 当日补录

补录固定 3 题，全部必答，且只作用于当次生成：

| 字段 | 题面 | 选项 |
|:-----|:-----|:-----|
| `headSense` | 此刻你的头面体感更接近哪一种？ | 轻松清明 / 微微发胀 / 有些上冲 |
| `sleepDuration` | 昨晚的睡眠时长大概如何？ | 少于 5 小时 / 5-7 小时 / 7 小时以上 |
| `tongueCoating` | 今天的舌苔观感更接近哪一种？ | 薄白 / 偏白偏厚 / 微黄 |

要求：

- 补录题不写入 `tianji_profile`
- 补录题真实进入检索与 Prompt
- 文案保持弱医疗表达

## 7. 结果卡

### 7.1 展示内容

结果卡只展示：

- 卦名
- 判词
- 白话解释
- 3 条避坑建议
- 2 组宜忌
- 节气、干支、生成时间
- 当次补录摘要

不展示：

- 医疗结论
- 趋势分析
- 原始知识库 id

### 7.2 操作

- `保存长图`
- `再起一卦`
- `查看历史`

## 9. 配额与异常

### 9.1 配额规则

- 每日最多 5 次
- 按 `Asia/Shanghai` 自然日 `00:00` 重置
- 成功拿到结果卡就计数，包括 fallback 结果
- 校验失败、网络失败不计数

### 9.2 异常处理

| 场景 | 提示 | 行为 |
|:-----|:-----|:-----|
| 网络失败 | 天机暂时未显现，请稍后再试 | 保留补录页，允许重新生成 |
| AI 主路径失败但 fallback 成功 | 已为你生成基础天机 | 正常展示结果，计入额度 |
| 当日额度耗尽 | 今日天机已满，请明日再来 | 展示历史入口，不再允许新生成 |
| 定位拒绝 | 不影响核心体验 | 继续主链路，不再追问 |
