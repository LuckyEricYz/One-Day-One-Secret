# 用户交互流程

> 当前文档只描述 MVP 主链路，不再把后续能力混入现行流程。

## 1. 总体链路

```text
首次使用：
打开 H5
  -> 生成 tianji_client_id
  -> 5 题问卷
  -> 今日状态选择
  -> 长按生成
  -> 结果卡
  -> 保存长图 / 查看历史

非首次使用：
打开 H5
  -> 今日状态选择
  -> 长按生成
  -> 结果卡
  -> 保存长图 / 查看历史
```

## 2. 启动逻辑

启动时按以下顺序判断：

1. 若不存在 `tianji_client_id`，生成随机 UUID 并写入本地
2. 若不存在 `tianji_profile`，进入首次问卷
3. 若已存在画像，直接进入今日状态选择
4. 若当日已有生成记录，可从历史入口再次查看，不额外计数

## 3. 首次问卷

### 3.1 问卷结构

前 4 题单选，第 5 题多选：

| 题号 | 问题 | 选项 |
|:-----|:-----|:-----|
| 1 | 你的睡眠质量如何？ | 经常失眠浅眠 / 偶尔不好 / 一般都很好 |
| 2 | 你的手脚温度？ | 经常冰凉 / 有时偏凉 / 一般温暖 |
| 3 | 你的消化状况？ | 容易胀气不适 / 容易腹泻 / 很少有问题 |
| 4 | 你的情绪状态？ | 容易焦虑紧张 / 容易压抑低落 / 基本平稳 |
| 5 | 你有以下情况吗？ | 长期久坐 / 经常熬夜 / 饮食不规律 / 规律运动 / 无以上情况 |

### 3.2 结果写入

问卷完成后写入：

```json
{
  "constitution": "qi_deficiency",
  "healthTags": ["late_sleep", "sedentary"],
  "createdAt": "2026-04-11T13:30:00.000Z",
  "updatedAt": "2026-04-11T13:30:00.000Z",
  "version": 1
}
```

本地键固定为 `tianji_profile`。

## 4. 今日状态选择

### 4.1 状态枚举

- `happy`
- `calm`
- `tired`
- `anxious`
- `sad`
- `angry`

### 4.2 交互要求

- 页面首次可见后 300ms 内完成可交互
- 点击状态后立即进入长按页
- 不增加额外确认弹窗

## 5. 长按生成

### 5.1 行为规则

- 最短长按：`2000ms`
- 最长长按：`30000ms`
- 未达最短时长松开：提示“再静心一会儿”
- 达到最短时长后松开：立即请求 `/api/generate`

### 5.2 后台并行信息

在长按阶段可并行准备：

- `timestamp`
- `timezone`
- 授权后的 `location`

地理位置是可选项，拒绝授权不影响主链路。

## 6. 结果页

### 6.1 展示内容

结果页只展示：

- 卦名
- 判词
- 白话解释
- 3 条建议
- 2 组宜忌
- 节气、干支、生成时间

不展示以下信息：

- 体检式评分
- 医疗结论
- 舌诊结论
- 趋势预测

### 6.2 操作

- `保存长图`
- `再来一次`
- `查看历史`

## 8. 配额与异常

### 8.1 配额规则

- 每日最多 5 次
- 按 `Asia/Shanghai` 自然日 `00:00` 重置
- 成功拿到结果卡就计数，包括 fallback 结果
- 校验失败、网络失败不计数

### 8.2 异常处理

| 场景 | 提示 | 行为 |
|:-----|:-----|:-----|
| 网络失败 | 天机暂时未显现，请稍后再试 | 保留当前页面，允许重新请求 |
| AI 主平台失败但 fallback 成功 | 已为你生成基础天机 | 正常展示结果，计入额度 |
| 当日额度耗尽 | 今日天机已满，请明日再来 | 展示历史入口，不再允许新生成 |
| 定位拒绝 | 不影响核心体验 | 继续主链路，不再追问 |
