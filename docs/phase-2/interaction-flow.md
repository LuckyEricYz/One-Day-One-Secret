# 🔄 用户交互流程

> 完整的用户旅程设计：从打开应用到保存天机卡的每一步交互

---

## 1. 用户旅程总览

```
首次使用：
  打开 H5 → 欢迎页 → 体质录入(3-5题) → 呼吸引导 → 长按起卦 → 推演动画 → 天机卡 → 保存/分享

日常使用：
  打开 H5 → Emoji 状态选择 → 呼吸引导 → 长按起卦 → 推演动画 → 天机卡 → 保存/分享
```

---

## 2. 详细页面流程

### 2.1 启动判断

```
用户打开 H5
    │
    ├─ LocalStorage 无用户数据 ──→ 首次使用流程（2.2）
    │
    └─ LocalStorage 有用户数据 ──→ 日常使用流程（2.3）
```

### 2.2 首次使用流程

#### Step 1: 欢迎页

```
全屏暗色背景，中央渐显：

    ✦
  一日天机

  "天地有道，身心自知"

  [开始探索]  ← 鎏金色描边按钮
```

- 进入时 logo 和文字从 opacity 0 → 1，耗时 1.5 秒
- 底部可选的"了解更多"小字链接

#### Step 2: 体质录入

**共 5 个问题，单选卡片式，每题一屏**

| 题号 | 问题 | 选项 | 映射体质标签 |
|:-----|:-----|:-----|:-------------|
| 1 | 你的睡眠质量如何？ | 🌙 经常失眠浅眠 / 😴 偶尔不好 / 💤 一般都很好 | 阴虚/气虚/平和 |
| 2 | 你的手脚温度？ | 🧊 经常冰凉 / 🤲 有时偏凉 / 🔥 一般温暖 | 阳虚/气虚/平和 |
| 3 | 你的消化状况？ | 😣 容易胀气不适 / 🤢 容易腹泻 / 😋 很少有问题 | 气滞/痰湿/平和 |
| 4 | 你的情绪状态？ | 😰 容易焦虑紧张 / 😶 容易压抑低落 / 😌 基本平稳 | 气郁/气滞/平和 |
| 5 | 你有以下情况吗？（可多选） | 🦴 长期久坐 / 🌃 经常熬夜 / 🍺 饮食不规律 / 🏃 规律运动 / 无以上情况 | 追加健康标签 |

**交互细节**：
- 顶部进度条（鎏金色）
- 选中选项时有轻微振动反馈
- 可以左滑返回上一题
- 最后一题完成后渐变过渡到呼吸引导

**数据存储**：
```javascript
// LocalStorage: user_profile
{
  constitution: 'qi_deficiency',  // 综合判定的体质类型
  healthTags: ['长期熬夜', '久坐'],
  createdAt: '2026-04-11T13:30:00.000Z',
  version: 1  // 用于后续升级数据结构
}
```

### 2.3 日常使用流程

#### Step 1: Emoji 状态选择

```
  今日你的状态如何？

  😊    😌    😴    😰    😢    😤
```

- 进入动画：6 个 Emoji 依次从下方弹入（间隔 80ms）
- 选中后轻微放大 + 底部金色下划线
- 选中 1 秒后自动进入呼吸引导

#### Step 2: 呼吸引导

```
  全屏深色背景
  中央一个缓慢呼吸的光圈
  
  "吸气…"  (光圈扩大 2 秒)
       ↓
  "呼气…"  (光圈缩小 2 秒)
       ↓
  重复 2 次后
       ↓
  "请长按屏幕，感应今日天机"
```

- 光圈颜色：鎏金色渐变光晕
- 文字过渡：淡入淡出
- 总时长约 8-10 秒
- 可以点击"跳过"（右上角小字）

#### Step 3: 长按起卦

```
  中央太极图标 ☯
  
  "长按感应天机"
  
  用户长按时：
  ├─ 周围粒子向中心聚拢
  ├─ 按钮边缘光晕增强
  ├─ 经过 2 秒后可松开
  └─ 松开 → 触发推演
  
  未满 2 秒松开：
  └─ 粒子散开，提示"再静心一会儿"
```

- 后台同时获取：地理位置、天气信息
- 按压时长记录精确到毫秒

#### Step 4: 推演动画

```
  时间线 (3 秒)：

  0s ─────────── 1s ─────────── 2s ─────────── 3s
  粒子爆散        粒子重组为六爻    卦名渐显         过渡到天机卡
  ↑ 松开瞬间     从下到上逐行成型   书法字体从中心    背景模糊化
                                   扩散显现          卡片入场
```

- 同时后台调用 `/api/generate`
- 如果 API 响应比动画快 → 动画结束后直接显示
- 如果 API 响应比动画慢 → 动画结束后显示 shimmer loading

#### Step 5: 天机卡展示

```
  卡片从底部滑入

  内容依次入场：
  1. 卦象 + 卦名 (0ms)
  2. 天机语 (200ms)
  3. 分割线 (400ms)
  4. 养生建议 (600ms)
  5. 宜忌标签 (800ms)
  6. 底部日期 (1000ms)
  7. 操作按钮 (1200ms)
```

**底部操作区：**
```
  [保存长图]     [重新起卦]
   ← 主按钮       ← 次按钮
```

#### Step 6: 保存 / 分享

```
  点击"保存长图"
      │
      ├─ 生成高清长图（含二维码水印）
      │
      ├─ iOS: 调用 share API → 系统分享面板
      │
      └─ Android/PC: 显示"长按保存图片"提示
```

## 3. 异常处理

### 3.1 网络异常

| 场景 | 用户提示 | 处理策略 |
|:-----|:---------|:---------|
| API 超时（>10s） | "天机暂隐，请稍后再试" | 重试按钮 + 离线天机兜底 |
| 完全无网络 | "需要网络连接来感应天机" | 检测到网络恢复后自动重试 |
| API 返回错误 | 根据错误码显示对应文案 | 见 api-spec.md 错误码表 |

### 3.2 交互异常

| 场景 | 处理 |
|:-----|:-----|
| 长按不足 2 秒 | 粒子回散，提示"再静心一会儿" |
| 长按超过 30 秒 | 自动触发起卦（正常流程） |
| 页面后台切换 | 暂停动画，回来后恢复 |
| 连续快速起卦 | 前端防抖，5 秒内不接受第二次 |

### 3.3 配额耗尽

```
  今日天机次数已用尽

  "每日五机，珍惜当下所得。
   明日辰时(7:00)，天机重启。"

  [回顾今日天机]  ← 查看今天已生成的最后一张
```

## 5. 地理位置 & 天气获取

### 5.1 流程

```
呼吸引导阶段（后台并行）：
1. 请求地理位置权限
   ├─ 授权 → 获取经纬度 → 调用天气 API
   └─ 拒绝 → 跳过天气维度，不影响核心功能
2. 天气数据（温度、湿度、天气类型）作为辅助信息注入 Prompt
```

### 5.2 天气 API 选择
- **MVP**：使用免费的 Open-Meteo API（无需 Key）
- **获取字段**：温度、湿度、天气代码
- **失败降级**：不影响核心流程，Prompt 中省略天气部分

## 6. 数据持久化

### 6.1 LocalStorage 数据结构

```javascript
// key: 'tianji_user_profile'
{
  constitution: 'qi_deficiency',
  healthTags: ['长期熬夜', '久坐'],
  createdAt: '2026-04-11',
  version: 1
}

// key: 'tianji_history'（第三阶段归档用，先预留结构）
[
  {
    date: '2026-04-11',
    mood: 'tired',
    result: { ... },  // 天机卡完整数据
    savedAt: '2026-04-11T13:30:00.000Z'
  }
]

// key: 'tianji_daily_count'
{
  date: '2026-04-11',
  count: 2
}
```

### 6.2 存储容量估算
- 每日天机数据约 2KB
- 保留 90 天历史 ≈ 180KB
- LocalStorage 限额 5MB → 绰绰有余
