# 用户交互流程

> 当前版本采用“资料先行、首页直达”的极简链路。

## 1. 总体链路

```text
首次使用：
打开应用
  -> v3 profile schema 校验，必要时清空旧 v2 角色历史
  -> / 自动跳转 /role
  -> 填写个人资料
  -> 自动弹出今日卦象
  -> 进入首页今日黄历与调理模块
  -> 可打开历史快照

非首次使用：
打开应用
  -> 读取上次资料
  -> 生成今日快照
  -> 自动弹出今日卦象
  -> 进入首页
  -> 可跳转 /role 修改资料 / 打开历史快照
```

## 2. 启动逻辑

1. 若不存在 `tianji_v3_profile`，访问 `/` 时自动进入 `/role`
2. 若已存在资料，直接生成当天快照
3. 若当天资料弹窗未读，默认弹出今日卦象
4. 历史快照始终可从头部入口查看
5. 已填资料访问 `/role` 时仍显示资料表单，用于修改后重新生成

## 3. 资料填写

字段：

- 性别：男 / 女
- 出生日期：必填
- 出生时辰：12 个传统时辰，可选择“不确定”
- 出生地：手动城市文本
- 当前所在地：手动城市文本

要求：

- 不请求浏览器定位
- 不上传资料
- 必填项缺失时不能提交
- 保存后立即进入当天内容
- 修改资料时重新计算当天快照

## 4. 今日卦象弹窗

### 4.1 触发规则

- 首次保存资料后立即弹出
- 已有资料时冷启动默认弹出
- 同一资料同一天关闭后，本会话和刷新后都不重复打断
- 跨日或修改资料后再次弹出

### 4.2 展示内容

必含：

- 卦名
- 六爻图
- 今日主轴
- 上下卦解释
- 2-3 个焦点标签

## 5. 首页模块

首页固定展示：

1. `今日黄历`
2. `今日状态提示`
3. `当日一卦`
4. `身体节律`
5. `带薪健身`
6. `每日穴位`
7. `节气食谱`

布局要求：

- 手机端单列
- 桌面端主内容 + 资料摘要侧栏
- 首屏不展示基础状态、情绪特质、年度喜忌等预设标签
- `带薪健身` 顶部展示 3 个预制静音循环动作视频，文字规则推荐仍保留

## 6. 每日自动更新

- 以 `Asia/Shanghai` 自然日 `00:00` 为准
- 跨日后重新生成 `DailySnapshot`
- 重新触发当天资料的卦象弹窗
- 同一天重复打开只复用同一份快照

## 7. 历史快照

### 7.1 规则

- 以 `profileHash + dateKey` 作为唯一键
- 同一资料每天只保留一条记录
- 列表按日期倒序显示

### 7.2 展示

- 日期
- 资料摘要
- 卦名
- 当天动作、穴位、食谱摘要

## 8. 本地存储

```text
tianji_v3_profile
tianji_v3_history
tianji_v3_modal_seen
tianji_v3_profile_schema
```

`tianji_v3_profile_schema` 用于资料 schema 改版清理。进入 v3 时会清除旧 `tianji_v2_*` 角色记录。
