# 性能策略

> 当前目标是在普通手机和桌面浏览器里稳定运行纯本地、资料驱动的养生面板。

## 1. 指标目标

| 指标 | 目标 |
|:-----|:-----|
| 首屏可交互时间 | `< 2.0s` |
| LCP | `< 2.5s` |
| CLS | `< 0.1` |
| 首页 JS gzip | `< 150KB` |

## 2. 首屏控制

- 首屏只加载资料页或首页所需资源
- `/role` 不加载角色视频头像，不直接引用源 MOV
- 健身动作使用优化后的 WebM + poster
- 所有日内容都来自本地规则和静态数据
- 纸面纹理继续用 CSS 渐变，不请求大图贴图
- 外部字体 CDN 继续禁用

## 3. 动效策略

- 页面转场仍以 `opacity` + `transform` 为主
- 卦象弹窗和历史抽屉只做轻量浮层动画
- 不依赖粒子球、长按交互、定位或长图导出

## 4. 更新策略

- 运行时只在 3 个时机重算快照：资料首次提交、资料被修改、上海时间跨日
- 同一资料同一天重复打开直接复用相同快照
- 历史写入按 `profileHash + dateKey` 去重，避免重复膨胀
- v3 schema 首次初始化会清理旧 `tianji_v2_*` 角色、历史和弹窗记录

## 5. 验收清单

- [ ] 首次进入资料页无明显卡顿
- [ ] 已有资料时能快速直达首页
- [ ] 弹窗出现和关闭都不影响页面滚动
- [ ] 跨日后自动更新快照
- [ ] 修改资料后生成新的 `profileHash`
- [ ] 历史记录不会因重复打开产生重复项
