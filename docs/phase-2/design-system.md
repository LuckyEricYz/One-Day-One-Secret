# 当前视觉规范

> 当前版本统一走“纸本留白”路线，强调清晰阅读和轻量养生面板。

## 1. 视觉方向

关键词：

- 宣纸
- 淡墨
- 朱砂
- 留白
- 温润

设计原则：

- 首页始终一次展示完整 4 模块
- 东方感来自材质、排版和节奏，不靠堆古典装饰
- 信息可读性优先于概念感

## 2. 颜色

| 变量 | 色值 | 用途 |
|:-----|:-----|:-----|
| `--color-page-bg` | `#efe4cf` | 页面大底 |
| `--color-paper` | `#f7f0df` | 宣纸主底 |
| `--color-paper-deep` | `#efdfc4` | 较深纸面层 |
| `--color-ink` | `#241b14` | 主文字 / 墨线 |
| `--color-muted` | `#6f6252` | 次级文字 |
| `--color-vermillion` | `#b64832` | 印章、主按钮 |
| `--color-gold` | `#9b7b46` | 点缀色 |
| `--color-line` | `rgba(54,33,16,0.14)` | 边框、分割线 |

## 3. 字体

- 主标题 / 卦名：`Songti SC`, `STSong`, `Noto Serif SC`, serif
- 正文 / 标签：`Noto Sans SC`, `PingFang SC`, system-ui

规则：

- 卦名和大标题用衬线
- 卡片说明、按钮、元信息用无衬线
- 不引入外部字体 CDN

## 4. 核心组件

### 4.1 角色卡

- 首屏双卡并列或堆叠
- 必含角色印章、基础状态、流年摘要、年度宜忌
- CTA 直达当天内容

### 4.2 卦象弹窗

- 以纸面浮层居中显示
- 卦象线条 + 卦名 + 今日主轴为视觉中心
- 关闭后直接回首页

### 4.3 首页模块卡

固定四块：

- 当日一卦
- 带薪健身
- 每日穴位
- 节气食谱

要求：

- 桌面端允许 2x2
- 手机端始终单列
- 单卡信息不超过两层结构

### 4.4 历史抽屉

- 仍保留抽屉式查看
- 左侧列表，右侧当日摘要
- 手机端改为上下结构

## 5. 动效

| 场景 | 时长 | 说明 |
|:-----|:-----|:-----|
| 页面入场 | `220-320ms` | 轻位移 + 渐显 |
| 卦象弹窗 | `220-280ms` | 浮层出现 |
| 历史抽屉 | `220-280ms` | 侧向滑入 |

约束：

- 动效必须可降级或关闭
- 不再依赖粒子球、长按进度环、复杂 canvas 动画

## 6. 响应式

- 手机：`360px-430px`
- 平板：`768px` 以内
- 桌面：`1024px+`

规则：

- 手机端结果始终单列
- 桌面端最多两列
- 不出现三列以上的信息密集面板
