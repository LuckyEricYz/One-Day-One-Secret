# MVP 视觉规范

> 目标是形成清晰、克制、可实现的视觉约束，而不是追求过度复杂的“概念稿”。

## 1. 视觉方向

关键词：

- 安静
- 留白
- 仪式感
- 低干扰

设计原则：

- 主链路只突出一个主操作
- 内容可读性优先于装饰感
- 动效只服务进入、长按、结果过渡三处

## 2. 颜色

| 变量 | 色值 | 用途 |
|:-----|:-----|:-----|
| `--color-bg` | `#0d0d0f` | 主背景 |
| `--color-surface` | `#17171b` | 卡片与弹层 |
| `--color-text` | `#f3efe7` | 主文字 |
| `--color-muted` | `#9b9487` | 次级文字 |
| `--color-accent` | `#c7a86a` | 主强调 |
| `--color-positive` | `#6d9a6b` | 宜与正向标签 |
| `--color-negative` | `#c66a55` | 忌与风险提示 |
| `--color-border` | `rgba(255,255,255,0.08)` | 分割与边框 |

## 3. 字体

MVP 不依赖外部字体 CDN，统一使用自托管字体或安全回退。

| 用途 | 字体建议 |
|:-----|:---------|
| 判词 | `LXGW WenKai`, serif |
| 正文 | `Noto Sans SC`, system-ui |
| 数字与时间 | `Noto Sans SC`, system-ui |

规则：

- 判词只在结果页使用书写感字体
- 其余页面保持现代无衬线，提高加载稳定性
- 不引入第三种装饰字体

## 4. 排版

| 层级 | 大小 | 用途 |
|:-----|:-----|:-----|
| Display | `2rem` | 判词 |
| H1 | `1.5rem` | 页面标题、卦名 |
| H2 | `1.125rem` | 模块标题 |
| Body | `0.95rem` | 正文建议 |
| Caption | `0.8rem` | 日期、说明、提示 |

规则：

- 主文案宽度优先控制在 16-20 汉字每行
- 建议列表保持单行可扫读，必要时换行
- 文案间距比普通 H5 稍大，但不超过 32px 节距

## 5. 核心组件

### 5.1 主按钮

- 高度：`48px`
- 圆角：`14px`
- 填充：`--color-accent`
- 同屏只出现 1 个主按钮

### 5.2 状态选择器

- 6 个状态等宽排列
- 选中态使用边框和缩放，不使用复杂发光
- 文字标签常显，避免仅靠 emoji 区分

### 5.3 长按按钮

- 直径：`112px`
- 视觉中心要明显，可承载进度反馈
- 粒子数量控制在 20-30 个
- 低端设备降级为环形进度，不保留粒子

### 5.4 天机卡

必含信息：

- 卦名
- 判词
- 白话解释
- 建议列表
- 宜忌标签
- 节气与时间

卡片规则：

- 宽度：`min(360px, calc(100vw - 32px))`
- 内边距：`24px`
- 背景采用纯色或轻微渐变
- 不叠加大面积高噪点纹理

## 6. 动效

MVP 只允许三类动效：

| 场景 | 时长 | 要求 |
|:-----|:-----|:-----|
| 页面入场 | `250-350ms` | 位移 + 渐显 |
| 长按反馈 | `2000ms` 内连续反馈 | 提供明确完成感 |
| 结果卡入场 | `400-600ms` | 卡片和内容顺序显现 |

约束：

- 不使用持续 3 秒以上的纯装饰动画
- 动效必须允许降级或关闭
- 低端机优先保内容，不保特效

## 7. 响应式

目标设备：

- 360px-430px 手机宽度优先
- 768px 以内平板次要适配

规则：

- 小屏优先，避免在移动端堆两列信息
- 结果卡始终单列
- 底部操作区要避开安全区

## 8. 明确不做

- 不依赖 Google Fonts
- 不追求“粒子成卦”级别的复杂视觉作为上线前提
- 不把装饰插画、Lottie、纹理资源设为 MVP 必备项
