# 当前视觉规范

> 当前版本统一走“黄色暖纸面 + 卡通轻养生”路线，首页优先强调今日黄历和状态提示。

## 1. 视觉方向

关键词：

- 暖黄纸面
- 奶白面板
- 棕色粗边
- 橙黄按钮
- 少量清新绿健康点缀

设计原则：

- `/role` 是个人资料页，不再展示角色卡和预设标签
- 首页首屏优先显示“今日黄历”“今日状态提示”“宜 / 忌”
- 卦象、节气、健身、穴位、食谱作为辅助模块继续保留
- 东方感来自纸面、卦象和排版节奏，不靠堆叠复杂装饰

## 2. 颜色

| 变量 | 色值 | 用途 |
|:-----|:-----|:-----|
| `--color-page-bg` | `#f5c95c` | 页面大底 |
| `--color-paper` | `#fffbea` | 奶白纸面 |
| `--color-paper-deep` | `#ffedb7` | 深一点的暖纸面 |
| `--color-ink` | `#241b14` | 主文字 / 卦象线 |
| `--color-muted` | `#6f6252` | 次级文字 |
| `--color-vermillion` | `#d9542d` | 强调文字、警示点 |
| `--color-gold` | `#f0aa1d` | 主按钮和暖色点缀 |
| `--color-border-strong` | `#8a4b1d` | 粗边框 |
| `--color-health` | `#6f9f68` | 健康正向 chip / 小图标 |
| `--color-health-deep` | `#3f6f46` | 健康模块标题 |

绿色只作为 5-10% 辅助色使用，页面整体不能读成绿色主题。

## 3. 字体

- 主标题 / 卦名：`Songti SC`, `STSong`, `Noto Serif SC`, serif
- 正文 / 标签：`Noto Sans SC`, `PingFang SC`, system-ui

规则：

- 今日黄历标题、卦名和状态标题用衬线
- 表单字段、按钮、chip、模块说明用无衬线
- 不引入外部字体 CDN

## 4. 核心组件

### 4.1 个人资料页

- 字段：性别、出生日期、出生时辰、出生地、当前所在地
- 性别用双按钮分段控件
- 出生时辰用下拉，默认允许“不确定”
- 城市只手动输入，不触发定位权限
- CTA 为“生成今日内容”

### 4.2 首页黄历卡

- 首屏视觉中心是“今日黄历”和“今日状态提示”
- 大字号展示当天状态摘要
- `宜 / 忌` chip 要比长段说明更抢眼
- 卦象线条必须上下长短对齐，避免像加载占位

### 4.3 卦象弹窗

- 以纸面浮层居中显示
- 卦象线条 + 卦名 + 今日主轴为视觉中心
- 关闭后直接回首页

### 4.4 首页辅助模块

固定模块：

- 身体节律
- 带薪健身
- 每日穴位
- 节气食谱

要求：

- 桌面端允许 2 列布局
- 手机端始终单列
- 单卡信息不超过两层结构

### 4.5 历史抽屉

- 仍保留抽屉式查看
- 以 `profileHash + dateKey` 保存快照
- 手机端改为上下结构

## 5. 动效

| 场景 | 时长 | 说明 |
|:-----|:-----|:-----|
| 页面入场 | `220-320ms` | 轻位移 + 渐显 |
| 卦象弹窗 | `220-280ms` | 浮层出现 |
| 历史抽屉 | `220-280ms` | 侧向滑入 |

约束：

- 动效必须可降级或关闭
- 不依赖粒子球、长按进度环、复杂 canvas 动画

## 6. 响应式

- 手机：`360px-430px`
- 平板：`768px` 以内
- 桌面：`1024px+`

规则：

- 手机端表单和结果始终单列
- 桌面端最多两列
- 不出现三列以上的信息密集面板
