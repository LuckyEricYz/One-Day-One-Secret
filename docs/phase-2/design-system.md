# 🎨 新中式视觉设计系统

> 「一日天机」的配色、字体、间距、组件规范与视觉语言定义

---

## 1. 设计理念

### 1.1 视觉关键词
- **玄**：深邃、神秘、暗色基调
- **雅**：克制、留白、不堆砌
- **润**：柔和的渐变与光影，不生硬
- **古今交融**：传统纹理 + 现代排版规则

### 1.2 设计原则
1. **以暗为基**：主背景为深色（墨色系），凸显内容的仪式感
2. **以金为线**：关键元素用鎏金色点缀（不滥用）
3. **以白为息**：大量留白（中式"气"的体现），间距大于常规 H5
4. **以动为魂**：微妙而流畅的动画，拒绝生硬切换

## 3. 字体系统

### 3.1 字体家族

| 用途 | 字体 | CSS 变量 | 加载方式 |
|:-----|:-----|:---------|:---------|
| 天机语（玄学判词） | 霞鹜文楷 (LXGW WenKai) | `--font-mystic` | Google Fonts CDN |
| 正文/说明 | Noto Sans SC | `--font-body` | Google Fonts CDN |
| 数字/日期 | DIN Alternate (或 Outfit) | `--font-mono` | Google Fonts CDN |

### 3.2 字号层级

| 层级 | 字号 | 行高 | 字重 | 用途 |
|:-----|:-----|:-----|:-----|:-----|
| Display | 32px / 2rem | 1.4 | 400 | 天机语（判词） |
| H1 | 24px / 1.5rem | 1.3 | 600 | 卦名、页面标题 |
| H2 | 18px / 1.125rem | 1.4 | 500 | 区块标题（身密码、宜忌） |
| Body | 15px / 0.9375rem | 1.7 | 400 | 正文养生建议 |
| Caption | 13px / 0.8125rem | 1.5 | 400 | 日期、节气、辅助信息 |
| Tiny | 11px / 0.6875rem | 1.4 | 400 | 标签、注脚 |

### 3.3 字体加载策略

```html
<!-- 预加载关键字体 -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=LXGW+WenKai&family=Noto+Sans+SC:wght@400;500;600&display=swap" rel="stylesheet">
```

- 使用 `font-display: swap` 避免 FOIT
- 天机语用的书法字体（LXGW WenKai）可接受闪烁，因为是结果页展示

## 4. 间距系统

### 4.1 基础单位

基数：`8px`，所有间距都是 8 的倍数（呼吸感）

| 变量名 | 值 | 用途 |
|:-------|:---|:-----|
| `--space-xs` | 4px | 极小间距（标签内距） |
| `--space-sm` | 8px | 小间距 |
| `--space-md` | 16px | 常规间距 |
| `--space-lg` | 24px | 区块间距 |
| `--space-xl` | 32px | 大区块间距 |
| `--space-2xl` | 48px | 页面级留白 |
| `--space-3xl` | 64px | 顶部/底部呼吸留白 |

### 4.2 页面边距
- 移动端左右边距：`24px`（比常规 16px 更宽，增加留白感）
- 安全区域：底部预留 `env(safe-area-inset-bottom)` for iPhone

## 7. 动画规范

### 7.1 缓动曲线

| 名称 | 值 | 用途 |
|:-----|:---|:-----|
| 入场 | `cubic-bezier(0.16, 1, 0.3, 1)` | 元素入场（快入慢出） |
| 退场 | `cubic-bezier(0.7, 0, 0.84, 0)` | 元素退场 |
| 弹性 | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 按钮点击反馈 |
| 呼吸 | `cubic-bezier(0.45, 0, 0.55, 1)` | 呼吸引导光圈 |

### 7.2 时长规范

| 类型 | 时长 | 用途 |
|:-----|:-----|:-----|
| 微交互 | 150-200ms | 按钮 hover、标签选中 |
| 过渡 | 300-400ms | 页面过渡、元素入场 |
| 动效 | 800-1200ms | 粒子聚散 |
| 仪式 | 3000-4000ms | 起卦推演动画 |
| 呼吸 | 4000ms (循环) | 呼吸引导光圈 |

### 7.3 关键动画描述

**呼吸引导**：
- 中心光圈以 4 秒为周期缓慢放大缩小
- 透明度在 0.05 - 0.15 之间变化
- 文字"吸气…" / "呼气…" 与光圈同步

**长按聚粒**：
- 30-50 个粒子散布在按钮周围 200px 范围
- 长按开始后粒子缓慢向中心聚拢
- 粒子大小 2-6px，鎏金色，随机透明度
- 松开后粒子爆散 → 过渡到推演动画

**推演成卦**：
- 粒子重新聚合，在中央排列成 6 行
- 每行粒子合并形成一根爻线（阳: 实线 / 阴: 断线）
- 卦象形成后，卦名以书法字体从中心扩散显现
- 总时长 3 秒

**天机卡入场**：
- 卡片从底部滑入，opacity 0 → 1
- 内容区块依次入场（卦名 → 天机语 → 建议 → 宜忌 → 日期）
- 每个区块间隔 150ms

## 8. 纹理与装饰素材

### 8.1 需要准备的素材
| 素材 | 格式 | 用途 | 尺寸 |
|:-----|:-----|:-----|:-----|
| 宣纸纹理 | WebP | 天机卡背景叠加（低透明度） | 512×512 可平铺 |

### 8.2 素材风格要求
- 纹理：极低对比度，仅作质感补充，不抢占内容
- 图标：线条风格，鎏金色描边，不填充
- 所有素材文件压缩至 < 50KB

## 9. 响应式适配

### 9.1 目标设备
- 主要：iPhone SE (375px) ~ iPhone 15 Pro Max (430px)
- 次要：Android 中端机 (360px-412px)
- 兼容：iPad Mini 竖屏 (768px)

### 9.2 断点
```css
/* 仅需一个断点区分手机与平板 */
@media (min-width: 768px) {
  /* 平板适配：内容区最大宽度 480px 居中 */
}
```

### 9.3 关键适配点
- 天机卡宽度：`min(340px, calc(100vw - 48px))`
- 文字不使用 px 绝对值定义，全部用 rem
- 测试机型优先级：iPhone 13 > iPhone SE > Samsung Galaxy S21
