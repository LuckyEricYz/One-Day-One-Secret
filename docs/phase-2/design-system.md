# 当前视觉规范

> 当前版本统一走“纸本留白”路线，不再使用暗色科技感底盘。

## 1. 视觉方向

关键词：

- 宣纸
- 淡墨
- 朱砂
- 留白
- 仪式感

设计原则：

- 主链路始终只突出一个当前动作
- 东方感来自材质、排版和节奏，不靠堆装饰纹样
- 结果可读性高于概念感

## 2. 颜色

| 变量 | 色值 | 用途 |
|:-----|:-----|:-----|
| `--color-page-bg` | `#efe4cf` | 页面大底 |
| `--color-paper` | `#f7f0df` | 宣纸主底 |
| `--color-paper-deep` | `#efdfc4` | 较深纸面层 |
| `--color-ink` | `#241b14` | 主文字 / 墨线 |
| `--color-muted` | `#6f6252` | 次级文字 |
| `--color-vermillion` | `#b64832` | 印章、主按钮 |
| `--color-gold` | `#9b7b46` | 少量点金 |
| `--color-positive` | `#587047` | 宜 |
| `--color-negative` | `#9a503d` | 忌 |
| `--color-line` | `rgba(54,33,16,0.14)` | 边框、分割线 |

## 3. 字体

统一使用系统可得字体回退，不依赖外部 CDN：

| 用途 | 字体建议 |
|:-----|:---------|
| 主标题 / 判词 | `Songti SC`, `STSong`, `Noto Serif SC`, serif |
| 正文 | `Noto Sans SC`, `PingFang SC`, system-ui |
| 英文标签 | `Noto Sans SC`, system-ui |

规则：

- 判词、卦名使用衬线
- 说明文字、按钮、元信息使用无衬线
- 不引入第三套装饰字体

## 4. 核心组件

### 4.1 纸面卡片

- 统一使用浅纸底 + 细边线 + 轻纤维纹理
- 圆角：`28-34px`
- 阴影：柔和，不做硬投影

### 4.2 印章按钮

- 视觉重心是朱砂而非高饱和渐变
- 高度：`48px`
- 只在当前主操作使用

### 4.3 粒子球

- 主视觉固定为流动粒子球
- Web：粒子更多，允许 hover 扰动与更明显的收束动画
- H5：粒子更少，强化长按进度环
- 降级后保留墨晕与成卦线条，不保留高密度粒子

### 4.4 即时预览卡

必含：

- 卦名
- 六爻形态
- 一句天机语
- 主 CTA：`注入你的生理能量，开启避坑指南`

### 4.5 补录卡

- 3 题单选，同屏完成
- 每题 3 个纸签式选项
- 强调“只作用于今天”

### 4.6 终极天机卡

必含：

- 卦名
- 判词
- 白话解释
- 3 条避坑建议
- 宜忌双区
- 节气 / 干支 / 时间
- 当次补录摘要

## 5. 动效

| 场景 | 时长 | 说明 |
|:-----|:-----|:-----|
| 页面入场 | `250-350ms` | 轻位移 + 渐显 |
| 粒子成卦 | `200-1200ms` | 粒子收束到六爻线条 |
| 即时预览切入 | `300-400ms` | 右侧纸卡滑入 |
| 终极卡入场 | `400-600ms` | 卡片整体显现 |

约束：

- 动效必须可降级或关闭
- 不使用重 Lottie
- 不用大量 DOM 粒子

## 6. Web / H5 差异

### 6.1 Web

- 主交互：点击粒子球
- 布局允许双栏
- Hover 扰动、粒子漂移和侧向预览更明显

### 6.2 H5

- 主交互：长按粒子球
- 单列优先
- 长按环和即时反馈优先于 hover 细节
- 底部安全区必须避让

## 7. 响应式

目标范围：

- 手机：`360px-430px`
- 平板：`768px` 以内
- 桌面：`1024px+`

规则：

- 手机端结果卡始终单列
- 桌面端允许“内容 + 侧边摘要”双栏
- 任何端都不出现超过 2 列的密集信息网格

## 8. 明确不做

- 不依赖 Google Fonts
- 不使用重型 3D 引擎作为上线前提
- 不把装饰插画、金箔边框、复杂古典纹样设为必需
