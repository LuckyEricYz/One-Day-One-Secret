# 👅 舌诊 AI 接入方案

> 从简易选择到 AI 拍照识别的渐进式舌诊功能设计

---

## 1. 渐进式实现路线

```
第二阶段（MVP）         第三阶段（AI 升级）
┌───────────┐          ┌──────────────────┐
│ 示意图选择  │  ──→    │  拍照 + AI 识别    │
│ 3 个典型舌象│          │  多模态 LLM 分析   │
│ 用户自主选择│          │  自动体质判定       │
└───────────┘          └──────────────────┘
```

---

## 2. MVP 阶段：示意图选择

### 2.1 三种典型舌象

| 选项 | 舌象描述 | 示意图风格 | 映射体质 |
|:-----|:---------|:-----------|:---------|
| A | 舌淡红苔薄白 | 健康的浅粉色，薄薄白苔 | 平和质 / 气虚质 |
| B | 舌红少苔 | 偏红色，苔很少或无苔 | 阴虚质 / 湿热质 |
| C | 舌淡胖有齿痕 | 偏淡色，舌体胖大，边缘有齿痕 | 阳虚质 / 痰湿质 |

### 2.2 交互设计

```
  你的舌头更接近哪种状态？
  （非必选，可跳过）

  ┌────┐  ┌────┐  ┌────┐
  │ 🔴 │  │ 🔴 │  │ 🔴 │   ← 示意图（插画风格，非真实照片）
  │ A  │  │ B  │  │ C  │
  └────┘  └────┘  └────┘
  淡红薄白  红少苔  淡胖齿痕

  [跳过此步]
```

- 使用手绘风格的舌头插画，避免真实图片引起不适
- 点击选项后展示简短说明（1 句话）

## 3. 第三阶段：AI 拍照识别

### 3.1 拍照流程

```
用户点击"舌诊拍照"
    │
    ▼
┌──────────────────────────┐
│  打开前置/后置摄像头       │
│  屏幕中央显示椭圆引导框    │
│  提示：张嘴，对准框内       │
│  光线检测：亮度 > 阈值      │
└───────────┬──────────────┘
            │ 拍照
            ▼
┌──────────────────────────┐
│  图像预处理                │
│  - 裁剪至舌头区域          │
│  - 色温标准化              │
│  - 压缩至 < 500KB          │
└───────────┬──────────────┘
            │
            ▼
┌──────────────────────────┐
│  调用 AI 多模态分析        │
│  (OpenAI GPT-4o Vision    │
│   或 Gemini Vision)       │
└───────────┬──────────────┘
            │
            ▼
┌──────────────────────────┐
│  解析结果 → 体质标签映射   │
│  更新用户画像               │
└──────────────────────────┘
```

### 3.2 拍照引导 UI

```
┌─────────────────────────┐
│                          │
│    ┌──────────────┐      │
│    │               │      │
│    │  (椭圆引导框)  │      │
│    │               │      │
│    └──────────────┘      │
│                          │
│  💡 请在明亮环境下拍摄     │
│  伸出舌头，对准框内        │
│                          │
```

### 3.3 AI 分析 Prompt

```
你是一位经验丰富的中医舌诊专家。请分析这张舌头照片，从以下维度判断：

1. 舌色：淡白 / 淡红 / 红 / 深红 / 紫暗
2. 舌形：正常 / 胖大 / 瘦薄 / 齿痕 / 裂纹
3. 舌苔色：白 / 黄 / 灰黑
4. 舌苔质：薄 / 厚 / 腻 / 少苔 / 无苔
5. 舌下络脉：正常 / 怒张（如可见）

请以 JSON 格式返回分析结果：
{
  "tongueColor": "淡红",
  "tongueShape": "齿痕",
  "coatingColor": "白",
  "coatingTexture": "薄",
  "sublingualVeins": "正常",
  "overallAssessment": "脾气虚弱，运化不足",
  "constitutionMapping": "qi_deficiency",
  "confidence": 0.75,
  "disclaimer": "此分析仅供参考，不构成医学诊断"
}

注意：
- 如果照片质量不佳（模糊、光线不足），返回 confidence < 0.5 并说明原因
- 必须附加免责声明
- 不要做任何疾病诊断
```

### 3.4 结果映射表

| 舌诊特征组合 | 推断体质 | 补充建议关键词 |
|:-------------|:---------|:---------------|
| 淡白 + 胖大 + 齿痕 + 白苔 | 阳虚质 | 温补、驱寒、忌生冷 |
| 红 + 瘦薄 + 少苔 | 阴虚质 | 滋阴、润燥、忌辛辣 |
| 淡红 + 正常 + 薄白苔 | 平和质 | 维持、均衡 |
| 红 + 正常 + 黄腻苔 | 湿热质 | 清热利湿、忌油腻 |
| 淡暗 + 紫暗 + 瘀斑 | 血瘀质 | 活血化瘀、注意运动 |
| 淡白 + 胖大 + 白腻苔 | 痰湿质 | 健脾祛湿、忌甜腻 |

### 3.5 隐私安全

- 舌头照片**不存储**在服务器，仅临时用于 AI 分析
- 分析完成后立即删除临时文件
- 仅存储结构化分析结果（舌色、舌形等文本标签）
- 明确告知用户：照片不会保存

---

## 4. 准确性评估

### 4.1 测试方案
- 收集 20+ 张不同体质的舌头测试图片
- 请中医师标注标准答案
- 对比 AI 输出与标准答案的一致率
- 目标：体质大类判定准确率 ≥ 70%

### 4.2 失败降级
- AI 返回 confidence < 0.5 时，提示用户改善拍照条件
- 连续 2 次低置信度，自动降级为示意图选择模式
