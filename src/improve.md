# 极简养生APP（优化版）
核心定位：**轻量易用、角色专属、每日一站式养生指南**，去掉冗余逻辑，保留核心实用功能，流程更顺滑、体验更直观。

## 一、核心功能优化（清晰简洁版）
1. **固定双角色预设**
   预制一男一女两个独立养生角色，每个角色内置完整基础档案：
   身体基础状况、生辰八字+流年大运、年度养生喜忌、日常情绪特质。
   无需用户手动输入，一键切换角色即可查看专属养生方案。

2. **每日智能生成专属卦象**
   系统自动匹配**角色基础状态 + 当天日期**，从周易64卦中精准生成1卦；
   打开APP自动弹出**卦象弹窗**，清晰展示：卦名、卦象图解、简易养生释义（贴合日常调理，不晦涩）。

3. **首页一站式养生面板**
   关闭卦象弹窗后，直接进入首页，展示4大核心模块，全是当天可用的实用内容：
   - 当日一卦：精简版卦象+养生指导
   - 带薪健身：1-2个办公室/居家简易动作
   - 每日穴位：1个养生穴位+按摩方法
   - 节气食谱：贴合当日节气的养生食谱

## 二、APP流程（超简单，用户零学习成本）
1. 打开APP → 选择性别角色
2. 自动弹出**今日卦象**弹窗 → 查看后关闭
3. 进入首页，查看当天全套专属养生内容
4. 每日零点自动更新卦象、健身、穴位、食谱，无需手动刷新

## 三、界面&内容亮点（适配简单开发）
- 无复杂交互，全是静态+每日更新内容，开发成本极低
- 卦象解释**通俗养生化**，不搞玄学，只讲作息、饮食、情绪调理
- 所有推荐内容**轻量化**：动作1分钟学会、按摩30秒完成、食谱家常易做
- 角色数据固定，不用数据库，直接预制配置即可实现

## 四、一句话Slogan（可选）
「双角色专属养生，每日一卦+一站式调理，简单好用」

---

### 总结
1. 核心：**双固定角色 + 每日自动卦象 + 4大实用养生模块**
2. 优势：开发简单、操作无脑、内容刚需，完全符合「简单养生APP」定位
3. 流程：选角色 → 看卦象 → 用养生方案，三步搞定
