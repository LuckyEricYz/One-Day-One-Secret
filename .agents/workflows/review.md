description: 自动总结暂存区代码并生成单句 commit，附带 issue 号
---

当用户输入 `/review` 时，请严格按照以下步骤执行：

1. 运行 `git diff --staged` 命令以获取当前暂存区的代码更改。如果没有暂存任何文件，请提示用户并结束流程。
2. 分析代码更改的内容，并生成一句**极其精简**的总结，概括代码的核心变动。这句总结要求：**只保留一句话，不要有任何多余的描述（desc）、不要用列表**。
3. 检查用户输入 `/review` 时是否提供了 issue 号（如 `/review 123` 或 `/review #123`）：
   - 如果用户提供了 issue 号，请在单句总结下方**空两行**，并加上该 issue 号（格式为 `#issue号`）。
   - 如果用户没有提供，请在单句总结下方**空两行**，并加上占位符 `#issue号`。
// turbo
4. 运行 `git commit -m "<精简总结>

<issue号>"` 命令来提交代码。注意用换行符保证中间空两行。
